Details

Each capability is collapsed. Evidence links point to the diff sections and measured sources.

1. Context management and handoff - weaker - C1 M

Theirs. Fresh owner or compaction before the budget is spent; a portable handoff switches session or harness, while compaction reduces an existing session. Ours. Native recovery works at 967,737 → 41,893 tokens, but there were 13 decisions and 2 refused attempts, and task completion does not call the controller. The 89% pressure example still delivered another assignment.

Evidence. Codex §1; context audit §2; measured records; baseline.

2. Verification - weaker - C2 M

Theirs. A control skill drives the real app and a maintained feature map proves each user journey. Ours. Real runners are habitual (339 Vitest, 296 check, 56 E2E), but no generated verification skill or feature map appears in the audited scope; hx success is a run-protocol check, not acceptance of the user contract.

Evidence. Codex §2; baseline; Lauren's verification method.

3. Evals for skills and prompts - missing - C3 M

Theirs. Blinded comparison of the installed skill or prompt with a candidate, a separate judge, repeated cases and a promotion decision. Ours. No shared skill/prompt eval artifacts or gate; agentmem does have frozen domain evals, so the missing subject is the shared skill and prompt layer, not all evals.

Evidence. Codex §3; baseline correction on agentmem evals; Devin §8; baseline.

4. Planning and project workflow (I-6) - weaker - C9 M

Theirs. A written chain from spec to plan to tasks to thin slices, with review and revision. Ours. 165 briefs show plan-first is real, but there is one plan.md, no ADR habit, and amendments travel as chat messages rather than versioned artifacts.

Evidence. Devin §4; baseline; capability 4.

5. Delegation and parallel agents - weaker - C4 M + C5 L

Theirs. Staged trust, isolated workers, bounded contracts and independent review. Ours. 9 of 21 routed outcomes failed (43%), and every failure is a tool-permission denial; two tasks retried the same cause. The control is real, but prerequisites are not settled before dispatch.

Evidence. Codex §5; baseline; capability 5.

6. Review - weaker - C6 M + C7 S

Theirs. Fresh reviewer gets artifact plus contract, not the author's claim; findings are classified, units are small, and acceptance is explicit. Ours. There are 40 requested review rounds and real defects were found, but no durable acceptance record binds a verdict to the accepted snapshot. Coverage is unknown, not single-digit percent.

Evidence. Codex §6; 40-round recount; baseline.

7. Memory and knowledge - weaker - C10 S

Theirs. Durable artifacts: handoff, wiki, rules or git, so a fresh agent resumes without the old thread. Ours. The memory store exists, but the habit is near zero: memory skill 2×, Obsidian 4×, 10 vault commits in 14 days, and no handoff habit.

Evidence. Devin §7; context audit §2; baseline.

8. Skills and prompt design - weaker - C3 M

Theirs. Small, versioned, composable skills with clear invocation and an eval gate. Ours. 75 skill calls in 14 days, 78% in three skills; the entire leaf layer and all subagent sessions invoked zero. The inventory is strong; trigger fidelity and regression discipline are not.

Evidence. Devin §8; baseline; capability 8.

9. Safety - weaker - C5 L

Theirs. Do not combine private data, untrusted content and egress in one execution principal; isolate and scope credentials. Ours. Command rules and redaction protect particular paths, but OpenCode allows arbitrary bash by default and the Codex trusted profile uses danger-full-access. No actual incident or successful adversarial test was established.

Evidence. Codex §9; capability 9.

10. Ambition, autonomy and taste - weaker - C11 S

Theirs. Judgment is the scarce input: ambition, an autonomy slider, taste and comprehension. Ours. Roles and human gates are well placed, but there are 0 WHY lines, no discard accounting, and no deliberately larger task in the window. Comprehension debt and reject-without-guilt are unpracticed.

Evidence. Devin §10; baseline; capability 10.

11. Harness and environment design - weaker - C8 M

Theirs. Treat model plus harness as one versioned artifact with one policy, a doctor and recovery. Ours. Shared sync works, but the adapters drift: Qwen is pinned in the launch overlay while policy defaults to DeepSeek, and the Devin prompt still puts review text in notes. A file-tree sync is not a behavior test.

Evidence. Codex §11; capability 11.

12. Code shape and constraints - weaker - C7 S

Theirs. Hard checks: types, lint, import boundaries, and every repeated review comment becomes a rule. Ours. The generic base is strong (strict TS, zod, eslint, npm run check), but AGENTS.md is two lines, there is no CONSTRAINTS.md, and correct has 0 invocations. The compounding meta-rule has never run.

Evidence. Devin §12; baseline; capability 12.

13. Model training and research loops - missing - C12 M

Theirs. Autoresearch: one editable file, a fixed budget, a metric and keep/discard. Ours. No shared layer has a training surface or an experiment loop. The training-literal half does not fit; the transferable loop shape is the gap, with the trading backtests as the closest pilot surface.

Evidence. Devin §13; capability 13.
